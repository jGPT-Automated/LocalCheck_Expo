# LocalPlus device-preview checkpoint

The default court is labeled in its sport line in Explore. Home and Schedule use the same saved-court rows, with a check for the current view. Settings owns the default and the per-court auto check-in preferences.

These are Expo web screenshots backed by the actual branch RPCs running in isolated PostgreSQL with fixture accounts. At each width the journey added a court, picked it independently on Home and Schedule, changed the default and one auto check-in preference, reloaded, and removed the other court. All 15 captures passed the clipping and overlap audit. Native background arrival and exit still need an iOS build and Always location access.
