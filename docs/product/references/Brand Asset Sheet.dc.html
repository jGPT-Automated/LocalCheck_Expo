BRAND ASSET SHEET
One accent, one identity. Sport is metadata (a badge on a profile), not a coloring system.
1 — Logo & Identity
Simplified back to one accent. Two sport colors on the mark read like a holiday badge — the brand needs to stay singular so it doesn't compete with anything. Tight viewfinder brackets, off-white. Orange checkmark — the one color in the whole system that means "brand."
LOCALCHECK

checkmark = #FF5500 — the only color the mark ever uses
clear-space = 0.25 × mark width · min-size = 24px standalone
wordmark-tracking = 1.5px @ Oswald 500

4 — Component States
Button (single accent), and the Smart Avatar — now an elevated, skeuomorphic surface.
Check-In Button — Live Transition
Solid and actionable when you're out. Once tapped, it confirms clearly and stops calling for action.
tap to toggle · animates 350ms
Button.styles.ts
const styles = StyleSheet.create({
  button: { flexDirection: 'row', gap: 8, paddingVertical: 14, paddingHorizontal: 24, borderRadius: 3,
    transitionDuration: '350ms' },
  // out — solid accent, fully actionable
  default: { backgroundColor: Colors.accent, borderColor: 'transparent' },
  // checked in — outline confirms state, no longer a CTA
  checkedIn: { backgroundColor: 'rgba(255,85,0,0.12)', borderWidth: 1.5, borderColor: Colors.accent,
    shadowColor: Colors.accent, shadowOpacity: 0.35, shadowRadius: 16 },
});
Smart Avatar — Elevated Box, Glowing Initials, Star Badge
No brackets on profile boxes — the bracket motif is reserved for the logo. Being on-court now is signaled by the initials glowing, never by an outline. Friend = star badge. Private players show no initials at all.
