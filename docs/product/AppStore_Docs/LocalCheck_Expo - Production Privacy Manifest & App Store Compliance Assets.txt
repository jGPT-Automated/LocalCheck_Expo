Asset 3: App Store Connect Privacy Questionnaire Box-Checking Checklist
Target Location: App Store Connect -> App Privacy Section


1. Data Collection Question:
   * Select Yes (App collects data).
2. Selected Data Categories:
   * Location: Check Precise Location
   * Contact Info: Check Name and Email Address
   * User Content: Check Photos or Videos
   * Identifiers: Check User ID
3. Category Configuration Answers:
   * Precise Location: App Functionality | Linked to User: Yes | Tracking: No
|---|
   * Email Address: App Functionality | Linked to User: Yes | Tracking: No
   * Photos or Videos: App Functionality | Linked to User: Yes | Tracking: No
   * User ID: App Functionality | Linked to User: Yes | Tracking: No
